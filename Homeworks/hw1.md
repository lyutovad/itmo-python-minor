# Формат сдачи

Домашняя работа сдаётся **только в формате `.ipynb`**.

Имя файла:

```text
homework_1.ipynb
```

Файлы `.py`, `.html`, `.pdf` и другие форматы вместо ноутбука не принимаются.

## Как должен быть оформлен ноутбук

Для каждого задания должен быть отдельный блок.

Перед решением задания добавьте **Markdown-ячейку**, в которой указаны как минимум:

- номер задания;
- название или краткое описание того, что требуется сделать.

Например:

```markdown
## Задание 2. Очистка данных

Нужно очистить имена и города, а суммы заказов преобразовать в числа.
```

После описания размещайте код решения.

Код следует делить на **логические ячейки**. Не нужно создавать отдельную ячейку для каждой строки, но и помещать всю домашнюю работу в одну огромную кодовую ячейку тоже не нужно.

Пример нормальной структуры:

```text
Markdown: Задание 1. Исходные данные
Code: загрузка / создание данных

Markdown: Задание 2. Очистка
Code: функции очистки
Code: применение функций

Markdown: Задание 3. Анализ
Code: подсчёты
Code: вывод результатов
```

# Понижающий коэффициент за оформление

Одной из целей курса является умение работать с Jupyter Notebook, поэтому структура ноутбука учитывается при проверке.

Если домашняя работа фактически сдана **одной большой кодовой ячейкой** или почти вся работа находится в одной ячейке без Markdown-разделения по заданиям, применяется понижающий коэффициент:

```text
итоговый балл = балл за содержание × 0.7
```

Например:

```text
за содержание: 18 баллов
коэффициент: 0.7
итог: 12.6 балла
```

Коэффициент применяется не за количество ячеек само по себе, а за отсутствие нормальной структуры ноутбука.

Если решение разбито на понятные логические блоки и задания оформлены Markdown-ячейками, коэффициент не применяется.

1. Циклы: три схемы, которые нужны постоянно

Сначала учимся видеть алгоритм. Короткая запись важна меньше, чем понимание того, что происходит на каждом шаге.

Счётчик

count = 0

for value in values:
    if value > 0:
        count += 1

Накопление суммы

total = 0

for value in values:
    total += value

Формирование нового списка

result = []

for value in values:
    if value > 0:
        result.append(value)

Список словарей

users = [
    {"name": "Анна", "age": 25},
    {"name": "Иван", "age": 17},
]

for user in users:
    if user["age"] >= 18:
        print(user["name"])

2. Функции: упаковываем знакомую логику

Параметр, аргумент и return

def is_adult(age):
    return age >= 18

result = is_adult(25)
  • age в определении — параметр;
  • 25 в вызове — аргумент;
  • return возвращает значение в программу.

Функция с условием

def classify_age(age):
    if age < 18:
        return "minor"
    elif age < 65:
        return "adult"
    return "senior"

Функция с циклом

def count_adults(ages):
    count = 0

    for age in ages:
        if age >= 18:
            count += 1

    return count

Одна функция вызывает другую

def normalize_city(city):
    return city.strip().lower()

def is_moscow(city):
    return normalize_city(city) == "москва"
Хорошая функция обычно решает одну понятную задачу. Это делает код проще для чтения, проверки и повторного использования.

3. Объекты: что важно перед NumPy и Pandas

Класс и объект

class Student:
    def __init__(self, name, age):
        self.name = name
        self.age = age

student = Student("Анна", 25)
  • Student — класс;
  • student — объект;
  • student.name и student.age — атрибуты.

Метод

class Student:
    def __init__(self, name, age):
        self.name = name
        self.age = age

    def introduce(self):
        return f"Меня зовут {self.name}"

student = Student("Анна", 25)
student.introduce()

Где нужны круглые скобки?

ЗаписьЧто это
len(values)вызов функции
values.append(4)вызов метода
student.ageчтение атрибута

Упрощённое правило для начала: круглые скобки означают вызов. Атрибут просто читаем — поэтому скобок нет.

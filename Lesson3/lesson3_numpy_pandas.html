NumPy: минимальный набор

Список Python универсален. Массив NumPy удобен для одинаковых операций над набором чисел.

values_list = [10, 20, 30]
values_list * 2
# [10, 20, 30, 10, 20, 30]

import numpy as np
values = np.array([10, 20, 30])
values * 2
# array([20, 40, 60])

Логическая маска

scores = np.array([45, 67, 82, 51, 90, 73])

scores >= 60
# [False, True, True, False, True, True]

scores[scores >= 60]
# [67, 82, 90, 73]

Несколько условий:

scores[(scores >= 60) & (scores < 80)]

Двумерный массив

data = np.array([
    [25, 1200],
    [31, 2300],
    [22, 900],
])

data.shape   # (3, 2)
data[:, 0]   # первый столбец
NumPy видит строки и столбцы, но не знает их смысл. Для обычной таблицы удобнее Pandas.

Pandas: первый DataFrame

import pandas as pd

records = [
    {"name": "Анна", "age": 25, "city": "Москва"},
    {"name": "Иван", "age": 17, "city": "Казань"},
]

data = pd.DataFrame(records)

DataFrame — класс, а data — созданный объект таблицы.

Фильтрация

data[data["age"] >= 18]

data[
    (data["age"] >= 18)
    & (data["city"] == "Москва")
]

Сортировка

data.sort_values("age")
data.sort_values("age", ascending=False)
По умолчанию sort_values() возвращает новый объект и не меняет исходный DataFrame.

Главный мост: логическая маска

NumPy

scores[scores >= 60]

Pandas

data[data["score"] >= 60]

В обоих случаях схема одна:

данные → условие → True/False → выбор подходящих элементов

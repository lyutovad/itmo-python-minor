Pandas: загрузка, выбор и фильтрация

Краткая методичка к занятию 4.
Теория
Квиз
Главная схема: CSV → DataFrame → осмотр → выбор столбцов → маска → фильтрация → сортировка.

1. Загрузка

import pandas as pd
data = pd.read_csv("file.csv")

DataFrame — таблица, Series — один столбец.

2. Быстрый осмотр

data.shape
data.columns
data.dtypes
data.head()
data.tail()
data.info()
data.describe()

3. Столбцы

data["amount"]                 # Series
data[["city", "amount"]]       # DataFrame

4. loc и iloc

ИдеяПример
ilocпо позицииdata.iloc[0:3, 0:2]
locпо метке / названиюdata.loc[0:2, ["city","amount"]]

5. Фильтрация

data[data["amount"] > 2000]

data[
    (data["city"] == "Москва")
    & (data["status"] == "paid")
]

Для нескольких условий используются & и |, а не and / or.

6. Полезные операции

data["city"].isin(["Москва", "Казань"])
data["amount"].between(1000, 3000)

data["city"].unique()
data["city"].nunique()
data["city"].value_counts()

data.sort_values("amount", ascending=False)
data.reset_index(drop=True)

Pandas: преобразования, строки, даты, groupby и merge

Краткая методичка к занятию 5.
Теория
Квиз
Главная линия: новые столбцы → строки → даты → groupby → merge → анализ объединённых данных.

1. Новый столбец

data["total"] = data["quantity"] * data["unit_price"]

Операция выполняется сразу над целыми столбцами — без ручного цикла.

2. Строковые методы

data["category_clean"] = (
    data["category"]
    .str.strip()
    .str.lower()
)

data["product"].str.contains("Книга")
data["product"].str.len()

Для строкового столбца используется пространство имён .str.

3. Даты

data["order_date"] = pd.to_datetime(data["order_date"])

data["order_date"].dt.year
data["order_date"].dt.month
data["order_date"].dt.day

.dt становится доступен после преобразования столбца в дату.

4. GroupBy

data.groupby("category")["total"].mean()

data.groupby("category")["total"].agg(
    ["count", "sum", "mean"]
)

Логика: разбить строки на группы → выбрать показатель → применить агрегат.

5. Merge

full_data = orders.merge(
    customers,
    on="customer_id",
    how="inner",
)
ТипСмысл
innerоставить только совпавшие ключи
leftсохранить все строки левой таблицы

6. Анализ после merge

full_data[
    full_data["status"] == "paid"
].groupby("city")["total"].sum()

После объединения можно анализировать показатели заказа вместе с признаками клиента.

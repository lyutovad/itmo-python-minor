Matplotlib и Seaborn

Matplotlib — базовая библиотека визуализации.

Seaborn работает поверх Matplotlib и удобен для статистических графиков и работы с Pandas DataFrame.

plt.figure(figsize=(8, 5))

sns.histplot(
    data=df,
    x="body_mass_g",
)

plt.title("Распределение массы")
plt.xlabel("Масса, г")
plt.ylabel("Количество")
plt.show()

Обычно через sns строим сам аналитический график, а через plt управляем размером и оформлением.

Одна категориальная переменная

Вопрос: сколько объектов относится к каждой категории?

sns.countplot(
    data=df,
    x="species",
)

Смотрим категории, частоты и возможный дисбаланс.

Одна числовая переменная

Histogram

sns.histplot(
    data=df,
    x="body_mass_g",
    bins=20,
)

Показывает форму распределения: центр, разброс, асимметрию, несколько групп и крайние значения.

Boxplot

sns.boxplot(
    data=df,
    x="body_mass_g",
)

Удобен для быстрого обзора медианы, разброса и потенциальных выбросов.

Histogram и boxplot показывают одну числовую переменную с разных сторон.

Категориальная + числовая переменная

Вопрос: отличается ли числовой показатель между группами?

sns.boxplot(
    data=df,
    x="species",
    y="body_mass_g",
)

Две числовые переменные

Вопрос: есть ли связь между двумя числовыми признаками?

sns.scatterplot(
    data=df,
    x="flipper_length_mm",
    y="body_mass_g",
)

Дополнительную категорию можно показать через hue:

sns.scatterplot(
    data=df,
    x="flipper_length_mm",
    y="body_mass_g",
    hue="species",
)

Две категориальные переменные

sns.countplot(
    data=df,
    x="species",
    hue="sex",
)

hue добавляет дополнительное разбиение по категории.

Несколько числовых признаков

corr = df[numeric_columns].corr()

sns.heatmap(
    corr,
    annot=True,
    vmin=-1,
    vmax=1,
)

Важно: корреляция показывает линейную связь, но сама по себе не доказывает причинность.

Что должно быть у аналитического графика

  • тип графика соответствует вопросу;
  • понятный заголовок;
  • подписанные оси;
  • единицы измерения, если они важны;
  • легенда, если без неё график непонятен;
  • короткий вывод после графика.
График без интерпретации — ещё не законченный анализ.

1. Выберите график

Нужно исследовать распределение возраста пассажиров.

Проверить идею

Возраст — числовая переменная. Хорошая отправная точка — histogram; дополнительно можно посмотреть boxplot.

2. Две переменные

Нужно понять, связаны ли длина ласта и масса пингвина.

Проверить идею

Обе переменные числовые → scatter plot.

3. Сравнение групп

Нужно сравнить стоимость билета между классами пассажиров Titanic.

Проверить идею

Класс — категориальная переменная, стоимость — числовая. Подходит boxplot по категориям.

4. Сформулируйте вопросы

Для знакомого DataFrame придумайте:

  1. вопрос про одну категориальную переменную;
  2. вопрос про одну числовую переменную;
  3. вопрос про связь двух переменных.

Для каждого вопроса выберите подходящий тип графика.

## Как сдавать домашние работы

Домашние работы сдаются через GitHub.

Базовый workflow:

```text
main
  ↓
создать ветку hw_n
  ↓
выполнить домашнюю работу
  ↓
commit
  ↓
push
  ↓
Pull Request
  ↓
review
  ↓
merge в main
```

Для сдачи работы:

1. Создайте **приватный репозиторий** на GitHub.
2. Дайте доступ преподавателю: `@lyutovad`.
3. Добавьте ссылку на репозиторий в таблицу курса.
4. Каждую домашнюю работу выполняйте в отдельной ветке `hw_n`.
5. Создайте Pull Request в `main`.
6. Добавьте `@lyutovad` как reviewer.
7. После ревью внесите необходимые исправления.
8. После принятия работы PR можно объединить с `main`.

Подробно Git и процесс сдачи домашней работы разберём на занятии 2.
